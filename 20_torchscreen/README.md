# 多点触控屏幕
## 一、 多点电容触摸屏简介
> 1. 多点触摸，不需要按下屏幕。
> 2. 电容触摸屏幕需要一个IC 驱动控制， 一般是 I2C 接口。多点触控屏幕驱动最终就是一个I2C设备。
> 3. 正点原子电容触控屏，4.3寸都是GT94147 IC，7寸2款，一个是FT5206，一个是FT5226。
> 触摸屏IP：
>> - CT_INT 触摸中断线，连接到GPIO1_IO09引脚。
>> - I2C2_CLK 连接到UART5_TXD引脚。
>> - I2C2_SDA 连接到UART5_RXD引脚。
>> - CT_RESET 复位引脚，连接到SNVS_TAMPER9引脚。
> 电容触摸芯片的输出触摸点坐标信息为对应的屏幕像素点信息，电阻屏幕需要校准。
## 二、FT54x6/FT52x6 电容触摸芯片简介
> 1. I2C 接口，最大400K频率。
> 2. FT5425的I2C 地址为0x38。
> 3. 需要用到的寄存器：
>> - DEVICE_MODE 0x00,需要设置为0x00，表示工作在正常模式。
>> - ID_G_LIB_VERSION_H 以及ID_G_LIB_VERSION_L 0xA1和0xA2，表示固件的版本号。
>> - ID_G_MODE 0xA4，设置FT5426 的工作模式，0是轮询模式，1是中断模式。设置为1表示采用中断方式上报触摸信息。
>> - TD_STATUS 0x02, 当前触摸点个数，1~5。
>> - TOUCH_XH 0x03开始，开始记录着触摸屏的坐标点信息。一个触摸点由6个寄存器表示，5个触控点需要5*6=30个寄存器。一直读取到0x20。
> 4. 一个触摸点坐标信息用12bit表示，其中H的bit[3:0]这4个bit为高4位，L寄存器的bit[7:0]为低8位。
> 5. 对于XH寄存器，bit[7:6]表示事件，很重要。
> YH 寄存器的bit[7:4] 表示触摸ID。
